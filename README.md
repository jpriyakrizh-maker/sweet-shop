# Gowmari Sweets — Diwali Landing Page

A traditional festive sweet-shop landing page built with React + Vite. All layout, styling, cards, decorative elements and interactions are coded; product photos load from remote image URLs.

## Run in VS Code

1. Extract this ZIP.
2. Open the `sweet-shop` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Included
- Responsive traditional maroon, cream and gold theme
- Hero section and Diwali offer banner
- Product cards with prices and Add to Cart
- Cart drawer with quantity updates and total calculation
- About, gift boxes, gallery, testimonials, contact and footer
- Scroll reveal animations with GSAP
- Map link for Palani Chettipatti, Theni
- Mobile navigation

## Important
The location is set to **Palani Chettipatti, Theni, Tamil Nadu 625531** based on the location discussed. Please confirm the exact shop name, address, phone number, product prices and offers before publishing. The product photos use external Unsplash image URLs, so internet access is required to display them. The cart is a front-end demo and does not submit real orders or payments.
